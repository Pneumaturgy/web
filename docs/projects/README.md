## One line of work, three bodies

[Navi](navi.md), [Mollusk](mollusk.md) and [Orison](orison.md) are the same
idea in different shapes: a local-model companion as a desktop fairy, a
living-room appliance, and a game master. They share the two-model local
pattern, and Navi's emotion system was reused in Orison.
